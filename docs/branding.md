# Kerd · เกิด: Branding v0.1

## ชื่อและ tagline
- **ชื่อ:** Kerd · เกิด (repo: `kerd`)
- **Tagline หลัก:** เดือนเกิดนี้ ได้อะไรบ้าง?
- **Tagline รอง:** รู้ก่อน สมัครก่อน ได้สิทธิ์ครบ
- **คำอธิบายสั้น (SEO meta):** รวมโปรวันเกิดและเดือนเกิดจากแบรนด์ดัง พร้อมวิธีใช้สิทธิ์ แหล่งที่มา และวันที่ตรวจล่าสุด

## บุคลิกแบรนด์
เหมือนเพื่อนที่จำวันเกิดเราได้: อบอุ่น เป็นกันเอง แต่ข้อมูลแม่นยำ
- ✅ พูดตรง บอกเงื่อนไขครบ บอกว่าข้อมูลตรวจเมื่อไร
- ✅ ภาษาง่าย ใช้ "คุณ" ไม่ใช้ศัพท์การตลาดเกินจริง
- ❌ ไม่ใช้ "ฟรีทุกอย่าง!", "ด่วนที่สุด!", ไม่ปั่นความรู้สึกให้รีบ
- ❌ ไม่ใช้โลโก้/รูปของแบรนด์อื่นโดยไม่ได้รับอนุญาต (ใช้ชื่อแบรนด์เป็นข้อความ)

## โลโก้ (concept)
เทียนวันเกิด 1 แท่ง เปลวไฟเป็นรูปเครื่องหมายถูก ✓ → สื่อทั้ง "วันเกิด" และ "ข้อมูลตรวจแล้ว"
- Wordmark: `kerd` ตัวพิมพ์เล็ก + `เกิด` ตัวเล็กด้านข้าง
- ต้องอ่านออกที่ขนาด favicon 16px (ใช้แค่เทียน + ✓)

## สี
| Token | Light | Dark | ใช้กับ |
|-------|-------|------|--------|
| `--brand` | `#FF6B5B` coral | `#FF8273` | ปุ่มหลัก, ไฮไลต์, โลโก้ |
| `--ink` | `#1F2A44` | `#E8ECF4` | ข้อความหลัก |
| `--muted` | `#5B6478` | `#A3ABBD` | ข้อความรอง |
| `--surface` | `#FFFFFF` | `#141A2A` | พื้นหลังการ์ด |
| `--bg` | `#FFF8F5` | `#0E1320` | พื้นหลังหน้า |
| `--fresh` | `#1E9E62` | `#3CC484` | badge "ตรวจแล้ว" |
| `--due` | `#C98A00` | `#F2B530` | badge "ถึงรอบต้องตรวจ" |
| `--warn` | `#D64545` | `#F07070` | badge ⚠️ "มีคนแจ้งปัญหา" |

ห้ามใช้ coral กับข้อความยาวบนพื้นขาว (contrast ไม่พอ) ให้ใช้กับปุ่ม/ไอคอน/หัวข้อขนาดใหญ่ ตรวจ contrast WCAG AA ตอนทำ UI จริง

## ตัวอักษร
- **IBM Plex Sans Thai** (หัวข้อ + เนื้อหา) หรือ **Noto Sans Thai** เป็นตัวสำรอง (ทั้งคู่ฟรีบน Google Fonts)
- ตัวเลขวันที่/badge: tabular numbers

## โดเมน (ยังไม่ได้ยืนยันว่าว่าง)
ตรวจจาก sandbox ไม่ได้ เพราะเครือข่ายบล็อก WHOIS/RDAP ต้องเช็กเองที่ registrar (เช่น Cloudflare Registrar, Namecheap) และ THNIC สำหรับ .th
| ลำดับ | โดเมน | หมายเหตุ |
|-------|-------|----------|
| 1 | `kerd.app` | สั้น, บังคับ HTTPS, เหมาะกับ web app |
| 2 | `kerd.co` | สั้น จำง่าย |
| 3 | `kerd.in.th` | บอกว่าเป็นไทย, ช่วย SEO ในไทย (บุคคลทั่วไปจดได้) |
| 4 | `getkerd.com` | ถ้า .app/.co ไม่ว่าง |
| - | `kerd.com` | คำ 4 ตัวอักษร .com มักถูกจดไปแล้ว |
| - | `kerd.co.th` | ต้องจดในนามนิติบุคคล |

แนะนำจด 1 ตัวหลัก + `kerd.in.th` redirect มาที่ตัวหลัก
